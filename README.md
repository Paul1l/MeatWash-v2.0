# MEATWASH — cinematic reference build

Публичный сайт: https://paul1l.github.io/MeatWash-v1.0/

Совместная разработка: [CONTRIBUTING.md](CONTRIBUTING.md) — ветки, проверки перед pull request и ловушка с бандлом сцены.

**Текущая версия (с 26 сентября 2026):** за основу взята версия https://meat-wash.vercel.app — первый экран на фотографиях (`dist/js/stage.js`, кадры `dist/assets/shots`), блок «До и после», «Гараж услуг» вместо «Примерочной». 3D-сцена Porsche страницей больше не загружается и не выкладывается (`scripts/prune-deploy.mjs`), но остаётся в репозитории. Разделы ниже про Three.js, GLB и бандл описывают эту 3D-сцену. Актуальное устройство — в `CLAUDE.md`.

GitHub Actions публикует содержимое `dist` через `.github/workflows/pages.yml` при каждом push в `main`. В Settings → Pages источник публикации — GitHub Actions; корень репозитория не является папкой сайта.

Готовый статический сайт по предоставленному `meatwash-site.zip` и скриншотам, с новой Three.js-сценой Porsche и GSAP ScrollTrigger.

## Запуск

Нужен Node.js. Запустите `START.cmd` или `npm start`. По умолчанию сервер использует порт 4173, START.cmd — 4176. Для другого порта задайте переменную `PORT`. Установка зависимостей для просмотра не нужна: Three.js, GSAP и ScrollTrigger включены в `dist/vendor`.

Открывать `dist/index.html` через `file://` нельзя: браузер блокирует ES modules и загрузку GLB. Используйте локальный сервер или любой статический HTTP-хостинг. Для публикации достаточно содержимого `dist`.

## Файлы

- `dist/index.html` — страница, навигация, четыре главы, блоки из референса, модальные окна.
- `dist/css/style.css` — исходная визуальная сетка макета, шрифты, карточки, секции.
- `dist/css/cinematic.css` — сцена, адаптация, статический режим, доступность.
- `dist/js/main.js` — ScrollTrigger, состояния интерфейса, загрузка сцены, cleanup, fallback.
- `dist/js/config.js` — цены, тексты и шесть позиций камеры.
- `dist/js/ui.js` — меню, клавиатура, модальные окна, запись и членство.
- `dist/js/scene.js` — модель, материалы, движение камеры, полировка, пакетирование геометрии.
- `dist/js/garage.js` — гараж, освещение, отражения, контактная тень.
- `dist/js/interior.js` — геометрия сидений, кожа, ткань, строчки, приборы, руль.
- `dist/js/water.js` — миллиметровые капли на геометрии капота, рост и скатывание.
- `dist/assets/img` — предоставленные изображения + `garage.webp`, фон без Porsche.
- `dist/assets/meatwash-content.json` — ранее предоставленные услуги, цены и источники.
- `dist/credits.html` — происхождение визуальных материалов и лицензии.
- `dist/robots.txt`, `dist/sitemap.xml` — индексация опубликованного адреса.
- `serve.cjs` — локальный сервер, без зависимостей.
- `scripts/check.mjs` — проверка синтаксиса, локальных ресурсов, ссылок и данных.
- `scripts/prune-deploy.mjs` — убирает из копии `dist` на раннере файлы, которые страница не запрашивает (исходный GLB, `ttf`, неиспользуемые логотипы и картинки, исходники three). В репозитории они остаются: их использует `npm run optimize`.

## Сценарий

0.00 — общий план; 0.20 — капот/крыло; 0.40 — интерьер; 0.60 — полировка заднего крыла; 0.80 — гидрофобные капли; 1.00 — отъезд камеры.

Первый экран сразу использует живую 3D-сцену Porsche 930 Turbo. Начальный общий ракурс совпадает с финальным: камера приближается к деталям при прокрутке и возвращается к той же машине. Фотографического вступления и подмены автомобиля больше нет. До готовности WebGL показываются интерфейс, запись и короткая подпись загрузки. Фотографии сохранены только для статического режима доступности и ошибки WebGL.

Между ракурсами камера идёт по полярной траектории вокруг машины. Материал лака меняет шероховатость и выраженность микрорисок. Капли — инстансы геометрии с IOR 1.333, расположенные raycast по капоту; скролл управляет ростом, движением и исчезновением.

## Производительность и доступность

Интерфейс доступен до готовности 3D; модель и модуль сцены загружаются параллельно. Активный GLB ~8.9 MB; максимальные встроенные текстуры 2048 px. Нет внешней CDN-зависимости и тяжёлого HDR. Reflection map создаётся один раз из гаража. DPR ограничен 1.25 на desktop и 1 на mobile; буфер преломлений использует половинное разрешение. Салон объединён по материалам, капли instanced; статическая тень обновляется один раз. При неподвижной камере рендер не работает постоянно. Скрытая вкладка не рендерится, обработчики и GPU-ресурсы освобождаются при уходе со страницы.

`prefers-reduced-motion: reduce` отключает загрузку 3D и делает главы статичными, без длинного закреплённого скролла. `?motion=reduce` позволяет проверить тот же режим вручную. При ошибке WebGL или потере контекста работает аналогичная версия с фотографиями. Диалоги используют native dialog, Escape и возврат фокуса; скрытые главы исключены из фокуса через inert. На мобильном есть постоянная запись.

Для локальной диагностики `#scene` содержит data-mode/data-progress, canvas — data-ready/data-progress/data-draw-calls/data-render-ms/data-frame-ms/data-textures. Это измерения текущего браузера, а не гарантия FPS на любом телефоне.

Данные сверены 23 сентября 2026 года с https://meat-wash.vercel.app: страницами `/programmy`, `/uslugi`, `/detailing`, `/adresa`, `/o-nas`. Полный каталог содержит 5 программ мойки, 20 цен для четырёх типов кузова и 39 работ в восьми категориях. Порошковая покраска дисков указана отдельно без выдуманной цены. Адреса, телефоны, часы работы, преимущества площадок, предложение для новых клиентов и способы оплаты перенесены из источника. Условия и окончательная стоимость уточняются перед работой.

Единый файл данных — `dist/assets/meatwash-content.json`. После изменения программ или услуг выполните `npm run catalog`, затем `npm run check` и сохраните обновлённый `dist/index.html`. Каталог генерируется в HTML, поэтому не требует дополнительного запроса или загрузки 3D. Переключатель типа кузова обновляет пять цен; раскрывающиеся списки работают через native details. Стили — `dist/css/catalog.css`. Модальные окна четырёх cinematic-глав ведут к соответствующим разделам полного прайса.

Онлайн-запись у площадок разная: Мясницкая — компания 906067 в `n975571.yclients.com`, Технопарк — компания 1743348 в `n1982508.yclients.com`. Общий адрес открывал только Мясницкую, поэтому окно записи и карточки локаций ведут в запись своей площадки. Адреса лежат в `meatwash-content.json` рядом с данными локации; `npm run check` следит, что обе ссылки есть на странице.

Неподтверждённые «1000+ клиентов» удалены. Рейтинг 5.0 указан в исходном сайте, отдельно по живой базе Яндекс Карт не проверялся. Блок клуба рассказывает о реальных сертификатах и корпоративном уходе, без выдуманного платного членства. Никакие заявки не имитируются и не отправляются локальным сервером. Yclients — внешняя система; автоматический выбор услуги и филиала через недокументированные параметры не используется.

## Оптимизация загрузки

Браузер загружает `porsche-930-optimized.glb` (8 937 688 байт) вместо исходных 14 919 340 байт: на 40% меньше. Meshopt сжимает и переставляет геометрию без упрощения или квантования; размеры текстур сохранены, удалены неиспользуемые и повторяющиеся ресурсы. Исходный GLB остаётся в проекте для повторной сборки, но не запрашивается страницей.

`scene.bundle.js` объединяет Three.js, загрузчик, Meshopt-декодер и сцену в минифицированный модуль (~638 КБ). Для его пересборки и оптимизации ресурсов после изменения сцены: `npm ci`, затем `npm run optimize` и `npm run check`. Исходники `scene.js`, `garage.js`, `interior.js`, `water.js` остаются редактируемыми.

Шрифты WOFF2 весят вместе 66 848 байт вместо 190 988 байт. После первого отображения hero модель и модуль сцены скачиваются параллельно. Инициализация больше не ждёт события загрузки всей страницы. При включённой экономии трафика браузера используется статическая версия без загрузки 3D.

Время загрузки 3D зависит также от декодирования, компиляции шейдеров и GPU. `data-load-ms` на `#scene` показывает полное время подготовки после первого кадра; `data-assets-ms`, `data-setup-ms`, `data-compile-ms` на canvas — накопленные времена этапов. Уменьшение веса не является обещанием одинакового ускорения на всех устройствах.

## Проверка исходников

`npm run check` проверяет исходники и ресурсы. Ручная проверка проводится во встроенном браузере: ракурсы, desktop/mobile, меню, цены, диалоги записи, reduced-motion, ошибки консоли и переполнение. См. `QA.md`.

Фон гаража `dist/assets/img/garage.webp` подготовлен встроенным imagegen из исходного `hero.webp`: удалён автомобиль и его тень, сохранены дерево, свет, кресла, фотографии и вывеска. Полный запрос сохранён в `IMAGE-PROMPT.md`.

Обновление 21 сентября: hero-hq.webp восстанавливает детали первого кадра; исходный hero.webp сохранён. Экспозиция 3D поднята с 0.86 до 0.98, усилены заполняющий свет и свет салона без новых источников или теней. Полный запрос — IMAGE-PROMPT.md.
